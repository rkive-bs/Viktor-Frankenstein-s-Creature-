# Gothic Novels Location Map

An interactive mapping website showcasing the haunting locations from five classic Gothic novels of the 18th and 19th centuries.

## Featured Novels

1. **Frankenstein** (1818) by Mary Shelley
2. **Northanger Abbey** (1817) by Jane Austen
3. **Jane Eyre** (1847) by Charlotte Brontë
4. **Wuthering Heights** (1847) by Emily Brontë
5. **Dracula** (1897) by Bram Stoker

## Features

- **Interactive Map**: Explore real-world locations from Gothic literature using Leaflet.js
- **Novel Filtering**: Filter locations by individual novel or view all at once
- **Detailed Information**: Each location includes:
  - Geographic coordinates
  - Novel and author information
  - Location description
  - Literary significance in the story
- **Gothic Theme**: Dark, atmospheric design inspired by Gothic aesthetics
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## Locations Included

### Frankenstein (1818)
- Geneva, Switzerland - Victor's family home
- Ingolstadt, Germany - University where the creature was created
- Mont Blanc, France - Victor's encounter with the creature
- Orkney Islands, Scotland - Destruction of the female creature
- Arctic Ocean - Final confrontation

### Jane Eyre (1847)
- Gateshead Hall - Jane's childhood

### Wuthering Heights (1847)
- Wuthering Heights - Earnshaw/Heathcliff residence
- Thrushcross Grange - Linton estate

### Dracula (1897)
- Castle Dracula, Transylvania - The vampire's lair
- Bistritz, Romania - Harker's last stop
- Whitby, England - Dracula's arrival
- London, England - Main battleground
- Carfax Estate, Purfleet - Dracula's English base

### Northanger Abbey (1817)
- Bath, England - Social center
- Northanger Abbey, Gloucestershire - The titular abbey
- Fullerton, England - Catherine's home

## How to Use

1. Open `index.html` in a web browser
2. The map displays all locations by default
3. Use the filter buttons to view locations from specific novels
4. Click on markers to see detailed information about each location
5. Zoom and pan the map to explore different regions

## Technologies Used

- **HTML5**: Structure
- **CSS3**: Styling with Gothic-inspired design
- **JavaScript**: Interactive functionality
- **Leaflet.js**: Interactive mapping library
- **CartoDB Dark Theme**: Map tiles for atmospheric effect
- **Google Fonts**: Crimson Text and IM Fell English SC

## Design Philosophy

The website features a dark, Gothic aesthetic with:
- Deep blacks and browns reminiscent of old manuscripts
- Gold accents (inspired by gilded book edges)
- Period-appropriate fonts
- Atmospheric shadows and borders
- Responsive layout for modern devices
